# Issue tracker: GitHub Issues

This repo tracks work in GitHub Issues on `Jefferson-Butler1/gm` (overrides the workspace `.scratch/` default).

## Wayfinding operations

- **Map:** one issue labelled `wayfinder:map`.
- **Tickets:** sub-issues of the map, each labelled `wayfinder:<research|prototype|grilling|task>`.
- **Blocking:** GitHub's native issue dependencies ("blocked by").
- **Claim:** assign the ticket to the driving dev before any work.
- **Frontier:** open, unassigned sub-issues of the map with no open blockers.
