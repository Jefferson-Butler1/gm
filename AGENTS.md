# Agent instructions

- **Asset credits:** every third-party asset (audio, textures, fonts, anything not made
  for this repo) must be CC0 or similarly permissive (MIT, OFL; CC-BY only with
  attribution) and verified against its source page before it's added. Credit it in
  `CREDITS.md` in the same change: the file, source URL, author, and license. That file
  is also the in-game credits roll, so keep its format (`##` sections, `-` lines).
- Issue tracker conventions: `docs/agents/issue-tracker.md`.
